# 来源与贡献范围

## 培训项目原型

- 原材料：用户保留的「科学文献研究智能体」2026 年 7 月培训项目 ZIP。
- 项目归属：四川华迪信息技术有限公司人工智能商业项目开发培训，2026-07-07 至 2026-07-16。
- 原实现：Python Streamlit 前端、FastAPI 后端；PubMed / arXiv 检索，固定调用 LLM 生成综述、空白分析、实验建议与写作内容。
- 用户原报告说明其主要工作围绕文献检索整合及 arXiv 工具；完整系统包含团队和 AI 辅助代码，不声称所有模块均由个人独立从零开发。

## 2026 年 10 月作品集升级（AI 辅助开发）

- 修复空查询、标题截断误去重、DOI 别名重复、检索失败被误认为无结果。
- 检索与模型初始化解耦；双源并发；来源诊断信息接入 API 和界面。
- 新增 `rag/`、PDF 文献库、BM25 检索、原生 tools 循环、引用校验、离线演示与测试。
- 新增 API / UI、README、面试讲解和数据排除规则。
- 新增共享研究工作区、四个类型化研究角色、产物交接事件、上下游依赖失效与人工问题选择。
- 整理便携启动方式，不再批量终止机器上的 Python / Streamlit 进程。

用户确认该培训项目可以上传。发布副本移除了硬编码 Key、`.env`、私人查询历史、缓存、旧机器绝对路径。原始材料保留在本机，未直接覆盖。未对团队原代码冒用个人独占版权；原材料未附统一许可证，因此不额外替第三方授予 MIT 等许可。

原有空白分析、实验设计与论文草稿属于历史模块，当前新增的严格引用门禁**只适用于 PDF 问答模块**。不要把新增门禁描述成所有历史生成模块已经具备的能力。
